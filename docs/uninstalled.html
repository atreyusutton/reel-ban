Reel Ban was just removed

This page opened because the extension was uninstalled. That was a deliberate action taken a moment ago.

What came back

  • YouTube Shorts — the swipe feed, the sidebar entry, the shelves on the home page and in search results.
  • Facebook Reels — the navigation link and the reels in the feed.

If that was not the plan

Reinstalling takes about a minute, and the PIN holder has to set it up again:

  • Chrome — open chrome://extensions, turn on Developer mode, click Load unpacked, choose the dist/chrome folder.
  • Firefox — open about:addons and install the signed .xpi again.

The PIN, the cooldown length and the typing sentence were stored with the extension and are gone. Setup starts from scratch.
