Reel Ban setup

This page is for the person holding the PIN, not the person being blocked.

Already set up

A PIN has already been chosen on this browser profile. Setup cannot be run again.

To change anything, open the options page and enter the PIN. There is no way to reset the PIN from here.

1. Choose a 4-digit PIN

There is no recovery. If this is forgotten, the only way back is removing the extension.

2. Cooldown

After the PIN and the sentence are both entered correctly, settings stay locked for this long. This is the part that actually works, and it cannot be changed later — only chosen now.

30 is the default. 0 disables the wait entirely, which is not recommended.

3. Typing challenge

This sentence must be typed out by hand, exactly, before the cooldown starts. Pasting is blocked. Also fixed once set.

4. Confirm

Once saved, the PIN, the cooldown length and the sentence are permanent for this installation.
